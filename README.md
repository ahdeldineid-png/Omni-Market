# ⚡ Arbitrage Hub - Binance Dark Terminal

Financial intelligence platform featuring real-time crypto spot prices (Binance API), EGX stocks & indices, global Forex converter, gold/Sagha pricing, and automated financial statement analysis.

## 🚀 Quick Start on Streamlit Cloud

1. Upload all repository files to GitHub.
2. Connect repository to [Streamlit Community Cloud](https://share.streamlit.io/).
3. Set Main File Path to `app.py`.
4. Deploy!

## 📦 Features
- 🪙 Binance Live Crypto Spot Terminal
- 🏛️ EGX 30 & EGX 70/50 Egyptian Stock Exchange Feeds
- 💱 Real-Time Forex Calculator (150+ Currencies)
- 🏆 Global Gold Spot & Sagha Premium Calculator
- 📈 Multi-year Financial Statement Ratio Analysis & Forecast Engine
