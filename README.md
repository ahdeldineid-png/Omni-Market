# ⚡ Arbitrage Hub & Financial Analyzer - Multilingual & Auto-Fetch Edition (V4)

Full-featured financial intelligence dashboard supporting **English & Arabic dual-language interface** and **automated financial statement fetching** for any public stock.

### New Key Features in V4:
1. 🌐 **Language Switcher (English / العربية)**: Instant full-UI translation across all 7 modules, charts, tables, and sidebars.
2. 🏛️ **Automated Financial Statement Fetcher**: Search any global or EGX stock symbol (e.g. `COMI.CA`, `AAPL`, `NVDA`, `MSFT`) to automatically pull multi-year income statements and balance sheets directly from stock exchanges.
3. 📊 **Instant Ratio Analysis & Year-4 Prediction**: Extract liquidity, profitability, and leverage ratios for any year and generate 4th-year linear/growth predictions without uploading files.
4. 📂 **Fallback Upload Option**: Retains custom Excel/CSV uploading functionality.
